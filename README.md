# Jamhuri Capital — classroom simulation

A static, fictional classroom demonstration showing how polished investment-style dashboards and recruitment narratives can create an impression of financial momentum.

## Safety boundaries
- No real deposits, payments, M-Pesa integration, withdrawals, or investment services.
- No collection of names, phone numbers, credentials, or other personal data.
- All balances, participants, events, and performance figures are fictional.
- Includes an end-of-experience debrief explaining pyramid-scheme mechanics and warning signs.

## Run locally
Open `index.html` in a browser, or deploy the repository as a static site (for example, with GitHub Pages or Vercel).

This is an educational prototype, not financial advice or a real investment opportunity.
